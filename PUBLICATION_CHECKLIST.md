# Publication checklist

- [ ] The pattern has a stable, documented interface.
- [ ] Environment-specific values are replaced with safe examples.
- [ ] No secrets, identifiers, inventories, state, logs, or evidence are present.
- [ ] Git history has been scanned for sensitive data.
- [ ] Destructive behavior and data-loss boundaries are documented.
- [ ] Validation, tests, rollback, and recovery guidance are included.
- [ ] Third-party sources, versions, notices, and licenses are recorded.
- [ ] An explicit license has been selected for the released artifact.
- [ ] CI validates formatting, syntax, security, and examples.
